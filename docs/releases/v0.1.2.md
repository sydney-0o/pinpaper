# Pinpaper v0.1.2

## English

- Fixed macOS bundle signing in CI. Both macOS DMGs now contain a complete ad-hoc signature, and CI verifies the app copied from the final mounted DMG with strict recursive code-signature checks, version checks, and architecture checks.
- Windows and Linux artifacts are rebuilt from the same versioned source.

### macOS first launch

The macOS DMGs are ad-hoc signed, not signed with an Apple Developer ID certificate, and not notarized by Apple. A complete ad-hoc signature prevents the previous incomplete-signature packaging failure, but it does not make the app trusted by Gatekeeper on every macOS version.

1. Download the DMG for your processor from this release and compare its SHA256 value with `SHA256SUMS.txt`.
2. Open the DMG and drag Pinpaper to Applications.
3. Try to open Pinpaper once.
4. If macOS blocks it, open **Apple menu → System Settings → Privacy & Security → Open Anyway**, then confirm **Open** after checking the source and checksum. This is a per-app approval; do not disable Gatekeeper globally.

The CI `codesign --verify --deep --strict` check passes on the app inside each final DMG. `spctl` may still reject an ad-hoc, non-notarized build; that result is expected and is not presented as Apple trust.

See [Apple's instructions for opening an app by overriding security settings](https://support.apple.com/en-us/guide/mac-help/mh40617/mac) for the per-app approval flow.

## Русский

- Исправлена подпись macOS-сборок в CI. Оба DMG теперь содержат полную ad-hoc-подпись, а CI проверяет приложение, скопированное из итогового смонтированного DMG: строгую рекурсивную подпись, версию и архитектуру.
- Сборки Windows и Linux пересобраны из того же источника версии 0.1.2.

### Первый запуск на macOS

DMG-файлы macOS подписаны ad-hoc, но не подписаны сертификатом Apple Developer ID и не прошли нотариальную проверку Apple. Полная ad-hoc-подпись устраняет прежнюю ошибку упаковки с неполной подписью, но не делает приложение доверенным для Gatekeeper на каждой версии macOS.

1. Скачайте DMG для своего процессора со страницы этого релиза и сравните SHA256 с `SHA256SUMS.txt`.
2. Откройте DMG и перетащите Pinpaper в «Программы».
3. Один раз попробуйте запустить Pinpaper.
4. Если macOS заблокировала запуск, откройте **Apple → Системные настройки → Конфиденциальность и безопасность → Открыть всё равно**, затем подтвердите **Открыть** после проверки источника и контрольной суммы. Это разрешение только для приложения; не отключайте Gatekeeper глобально.

Проверка CI `codesign --verify --deep --strict` проходит для приложения внутри каждого итогового DMG. `spctl` всё ещё может отклонить ad-hoc-сборку без нотариальной проверки; это ожидаемо и не выдаётся за доверие Apple.

См. [инструкцию Apple по открытию приложения через персональное исключение в настройках безопасности](https://support.apple.com/ru-ru/guide/mac-help/mh40617/mac).
